# ARC Explainer SEO audit and implementation

Author: GPT-6.1 Sol / Codex
Date: 2026-10-07

This pass applies the October 3 MarkSite and farm-site checklist to ARC Explainer's existing Express/React architecture. It is verified locally against production-built files and actual content registries. Deployment polling was explicitly excluded by the request.

## Shipped

| Area | Result |
| --- | --- |
| Initial HTML | 35 public SPA hubs get unique metadata, a readable summary and useful links. All 26 current/historical official game guides include real controls, per-level rules, screenshots and notes from the existing registry. The browser still replaces this with the interactive React view. |
| Puzzle discovery | Browser initial HTML links the 1,626 locally available puzzles. Individual puzzles get source-aware metadata and summaries. No invented model answers. |
| Sitemap | `/sitemap.xml` is generated from routes, game IDs and the puzzle loader: 1,689 canonical URLs in this checkout. Includes Human ARC's entry and the standalone human/AI comparison. Removes aliases, removed uploads, tools, session routes and the duplicate Markdown export. Unknown modification dates are omitted. |
| Canonicals | One preferred origin, `https://arc.markbarney.net`, including requests through the other public hostname. Query parameters do not create separate canonical pages. |
| Redirects/status | Server 308 redirects for known aliases and trailing slashes, preserving query strings. Unknown pages, official games, puzzle IDs and missing assets return 404 instead of a successful generic shell. API fallbacks remain JSON. |
| Indexing policy | Admin/configuration/solver-session routes receive both initial HTML noindex and X-Robots-Tag. Existing synthetic answer-key disallows remain intact. Noindex is not access control. |
| Structured data | Factual WebSite/WebPage descriptions and breadcrumbs that match visible navigation. Existing sourced analytics/competition descriptions retained. Removed the nonexistent root search action; no invented FAQ, ratings or credentials. |
| Client navigation | A common route component resets canonical, title, description, social card, robots and schema. Existing dynamic page hooks refine that state; older title-only effects use the same writer. Tested moving from an unindexed admin screen back to indexed home. |
| Sharing | Absolute image URLs, image alt metadata and a PNG fallback rasterized from the existing 1200×630 SVG. Official guides keep their own game image endpoint. |
| Internal links | Resource hub now links every public section. Guides, the Slippery Seven, results, research and both competition boards are connected. A missing-page screen gives recovery links. |
| Images/zoom | All 223 referenced game screenshots exist. Key page images already reserve space and lazy-load; those patterns were retained. Removed maximum-scale=1 so visitors can zoom. |
| Loading | 61 secondary page modules load on demand; homepage remains eager. A load-error boundary offers reload if a chunk becomes unavailable. Entry JS was about 3 MB before and is about 453 KB after (about 146 KB gzip). This is a bundle measurement, not a field Core Web Vitals claim. |
| AI discovery | llms.txt is a factual Markdown resource guide, distinct from robots.txt, and includes the two competition boards, research and the Slippery Seven. |

## Verification

- `npx vite build` and the existing esbuild server bundling command pass.
- `npx vitest run tests/integration/seo.test.ts tests/metaTagInjector.test.ts tests/humanArc.test.ts tests/leaderboardPresentation.test.ts`: 26 tests pass. Tests use actual registries and a local Express server serving the production shell.
- Every public hub and official guide: exactly one initial H1, title, description, canonical and robots tag; parseable JSON-LD. Metadata escapes quotes, markup and script terminators.
- Every generated SPA sitemap URL resolves to an indexable registered page or known puzzle/game. No synthetic answer keys or redirect aliases are included.
- Checked all 223 local game screenshots for existence; none missing.
- Local browser: Slippery Seven → dc22 lazy navigation updates canonical/OG/schema; admin → home clears noindex; resource hub renders its 35 public links and breadcrumbs. Preview intentionally did not connect live APIs or databases.
- `npx tsc --noEmit --pretty false` still reports the same unrelated diagnostics in SnakeBench controller, Johan Land ingestion and older test files/missing testing-library packages. No diagnostics in changed code. They are not claimed fixed by this pass.

## Limits and follow-through

- This extends initial HTML delivery; it does not migrate the whole application to React SSR. Live leaderboard tables, interactive puzzle grids and other API-driven results still populate in the browser. Raw HTML gives an honest description and discovery links, not fabricated or cached competition figures.
- Human ARC is a separately maintained frontend mounted under `/human-arc/`; this pass preserves its own routing/build. Its deeper pages need their own rendering/indexing review if that application is included in a future pass.
- Community play sessions remain noindex and are validated by their existing runtime/API. This pass validates missing official-guide and locally catalogued puzzle IDs at the HTML layer; it does not add network-dependent mirror catalog validation to every play-page request.
- Google Search Console ownership, sitemap submission and indexing reports were not accessed. The sitemap is advertised in robots.txt. External ranking, backlinks, field Core Web Vitals and third-party social-cache refresh are unverified; no ranking guarantee is made.
