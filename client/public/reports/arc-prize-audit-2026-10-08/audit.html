Feedback for Matt · October 9, 2026

Feature asks and missing resources

Matt—I’m a hobbyist, and ARC Explainer is a volunteer project I build in my own time, without earning anything from it. I built these features because I wanted to understand ARC and couldn’t find the tools I needed. I’ve offered to share the work with ARC Prize, and I’d be glad to see these capabilities become part of the official site. It’s been frustrating to see useful features remain missing after putting that work into making them available. These two asks point to existing implementations your coding assistant can build on.

  • Red Pill/Blue Pill archive — Direct archive link; original source: https://github.com/theredbluepill/arc-interactive

  • Son Pham’s ARC-3 games and agent harness — Browser games and agent runs.
  • Tufa Labs — Duck harness — Code and accompanying research: https://tufalabs.ai/research/duck-harness/

2. Make the underlying model attempt inspectable

ARC Explainer already shows released reasoning, submitted and expected grids, mismatch highlighting, and task-level cost/time. The official ARC-1/2 task table and newer pass/fail matrices stop short of that combined view.

Requested change: let a result row open the actual attempt, with those fields together. Add filtering for failed tasks and comparison of two model versions on the same task when both records exist. Show the source and model settings, and label unavailable fields.

Implementation references: saved reasoning and grid comparison · task/model analytics. Official counterpart: 13e47133 result table.

Existing open questions

I asked months ago why publication of the raw Hugging Face results had stopped and was told I would receive an answer; I’m still waiting. I’m beginning to assume publication won’t resume, although that hasn’t been confirmed. If that is the decision, it makes incorporating these inspection features into ARC Prize even more important: community tools can’t show newer attempts and released reasoning without access to the records. I’ve also asked about Opus 5.5 ARC-3 results. The practical concern is preserving people’s ability to examine how models reach their answers.
