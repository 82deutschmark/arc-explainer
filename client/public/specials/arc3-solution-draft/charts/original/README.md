# Original Claude charts — static exports

Source: https://claude.ai/artifact/1MN7SG2emwtxW2XKM7juNZ · read 6 November 2026.

The eleven SVG/PNG pairs are the original drawing definitions run once at a 900-pixel layout width, then exported as 1800-pixel PNGs. No animated intermediate state was captured. PNG backgrounds use the original panel color. `source-data.json` contains the original plotted arrays; `source-readable.txt` preserves original text/tables. `original-chart-definitions.js` is a preserved offline source, NOT loaded by the article. It deliberately excludes the animation/bootstrap section and all Claude frame runtime.

Reproduction uses the archived original article HTML in the canonical local report, the report’s `charts/static_original.cjs`, installed jsdom and sharp. No browser runtime, remote executable or new dependency is needed by the published page. Static trim/swap/wipe and hardware-box diagrams are retained as HTML; the looping trim video is omitted.

These are author-reported aggregate measurements from different workloads and dates, not newly reproduced runs or independent cumulative ablations. Consult every chart caption and its adjacent numerical table before comparison.
